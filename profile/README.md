## ❓ Frequently Asked Questions (FAQs)

#### 1. How do I change the default hotkey for Flow Launcher?

Open the Flow Launcher search bar (`Alt + Space`), type `Settings`, press **Enter**, navigate to the **General** settings tab, and set your preferred combination under **Hotkey**.

#### 2. Is Flow Launcher portable?

Yes. Flow Launcher offers a portable ZIP distribution that allows you to store settings, plugins, and logs in the local application folder without modifying registry keys.

#### 3. Can I run commands as Administrator directly from Flow Launcher?

Yes. Highlight any application, shell script, or system utility in the search results and press `Ctrl + Shift + Enter` to launch it with elevated Administrator rights.
